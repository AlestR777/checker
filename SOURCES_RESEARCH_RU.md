# Источники для ThreatWatch France v3

*Список проверенных публичных точек доступа/документации и дополнительных идей. Наличие сайта в списке не означает, что его API сейчас работает без ключа. Даты и технические ограничения нужно перепроверять в своей сети.*

| Источник | Адрес / документация | Реализация | Что даёт | Важное ограничение |
|---|---|---|---|---|
| Ransomfeed | https://api.ransomfeed.it/docs/html | v2/v3 подключён | Публичные утверждения о жертвах и группах | Это заявления криминальных группировок, не доказательства; агрегатор |
| RansomLook | https://www.ransomlook.io/ | v2/v3 подключён, тайм-аут 40 с | Публичный индекс заявлений | Может отвечать медленно; часто дублирует других агрегаторов |
| Ransomware.live | https://ransomware.live/ | Подготовлен адаптер, выключен | Хронология заявленных жертв | API/ключ/правила использования меняются |
| RansomWatch | https://github.com/joshhighet/ransomwatch | Идея для следующего адаптера | Метаданные публикаций групп | Формат/хостинг меняются, не загружать материалы с leak-sites |
| CERT-FR | https://cert.cyber.gouv.fr/flux-rss/ | RSS подключён | Официальные предупреждения | CVE в мире не доказывает наличие уязвимости у организации |
| CISA KEV | https://github.com/cisagov/kev-data | Через агрегированный CIRCL feed, прямой JSON не подключён | Известные эксплуатируемые CVE | Не назначать CVE конкретной организации без документированного факта использования |
| CIRCL Vulnerability Lookup | https://vulnerability.circl.lu/ | RSS подключён | Контекст уязвимостей | Не использовать как непосредственную метрику «уязвимости компании» |
| Google News | https://news.google.com/ | RSS-поиск подключён | Публикации СМИ по организациям и хактивизму | Весьма неполная выборка; перепечатки и задержки |
| BleepingComputer | https://www.bleepingcomputer.com/rss-feeds/ | RSS подключён | Новости инцидентов | Международный шум; возможные задержки |
| The Record | https://therecord.media/ | RSS опционален | Исследования и расследования | Проверять актуальный URL RSS и условия использования |
| Mastodon | https://docs.joinmastodon.org/methods/timelines/ | Включён публичный hashtag timeline, другие теги добавляются | Публичные посты аналитиков и исследователей | Некоторые инстансы отключают анонимный доступ; соцпост не подтверждение |
| Telegram (публичный предпросмотр) | https://t.me/s/ | Адаптер опционален, выключен | Публичные каналы с датами и текстом | Без входа, только открытый предпросмотр; HTML может измениться, проверять подлинность канала |
| Reddit public RSS | https://www.reddit.com/r/cybersecurity/new/.rss | RSS опционален, выключен | Тематические публичные публикации | 429/403, условия доступа; не обходить лимиты |
| ENISA | https://www.enisa.europa.eu/ | Исследовательский источник | Сравнение отраслей, оценка трендов | Отчёт за период, а не сигнал конкретной будущей атаки |
| FIRST EPSS | https://www.first.org/epss/ | Пока только для методологии | Вероятность эксплуатации CVE в мире | Не вероятность взлома конкретной компании; нужна доказанная релевантность продукта |
| ZATAZ | https://www.zataz.com/ | Ручные ссылки/опциональное чтение редакционных страниц | Французские публикации о киберугрозах | Уточнять дату события отдельно от даты статьи |

Для сравнения: независимые СМИ и CERT могут подтвердить наличие публикации или факт нарушения сервиса; два ransomware-агрегатора одной оригинальной записи **не являются двумя независимыми подтверждениями атаки**.

Если требуется больше наполнения, первыми улучшениями должны быть **расширение списка наблюдения и разбор неотнесённых материалов** — больше API без проверки качества даст много шума. Для Telegram выбирайте только реально публичные каналы, проверяйте их происхождение и не импортируйте личные данные либо содержимое утечек.
