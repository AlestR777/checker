# ThreatWatch Global v5.0 — графовый контекст и проверка качества

## Реализовано

- Восстанавливаемая из исходной базы **проверочная выборка** для качества извлечения организаций: случайная (фиксированный seed) смесь материалов с найденными и ненайденными именами; **без автозаполнения правильных ответов**.
- Оценка `precision`, `recall`, `F1`, ложных срабатываний и пропусков на **вручную проверенных** статьях.
- Исторически корректное время привязки публикации к организации `mentions.linked_at`, а также аттестация одобрения кандидата `entity_candidates.reviewed_at`.
- Миграция БД v4: исторически неизвестное время связи ставится как **время миграции**, не как выдуманная дата из прошлого; такие связи исключаются из более ранних срезов.
- Четыре ограниченных графовых показателя: число подтверждённых отношений, заявления о соседях по подтверждённым отношениям, контекст той же отрасли и той же страны. **Ни один показатель не доказывает готовящуюся атаку.**
- Новый строгий экспорт неразмеченных исторических срезов (`prepare-graph-history`) с датами, наблюдавшимися на момент расчёта, без использования позднее добавленных связей.
- Сравнение базовой 8-признаковой и расширенной 12-признаковой логистической модели при наличии независимых меток (`validate-graph`): Brier score, калибровка, постоянный baseline, временное разделение и 14-дневный embargo.
- Страницы `/graph` и `/quality`, JSON API `/api/graph`, отображение графового контекста в карточках организаций, статическое изображение только подтверждённых отношений.
- **Локальный ИИ остаётся необязательным**; команды `run`, `watch`, `prepare-graph-history`, `validate-graph` не требуют Ollama / OpenAI.

## Команды

```powershell
python -m threatwatch export-entity-audit exports/entity_review.csv --size 100
python -m threatwatch evaluate-entity-audit exports/entity_review.csv
python -m threatwatch graph-context edf
python -m threatwatch prepare-graph-history exports/graph_unlabelled.csv
python -m threatwatch validate-graph exports/graph_verified.csv
python -m threatwatch serve
```

## Главное ограничение

Обучение на реальных взломах не проведено: пользовательская SQLite-база и независимо подтверждённые положительные/отрицательные исходы отсутствуют в поставке. Данные старой версии без времени первоначального сопоставления не должны автоматически превращаться в обучающие примеры для прошлого. Вычисленные числа публикаций **не являются вероятностью взлома**. Сначала измеряется качество извлечения и накопления исторических данных, затем сравнивается модель на размеченной временной выборке.
