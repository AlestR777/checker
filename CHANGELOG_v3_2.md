# Изменения v3.2

- Исправлен необъявленный CLI-параметр `args.local_ai`, ломавший `run` и `watch` в предыдущем выпуске.
- Добавлены опциональные флаги `--local-ai`, `--local-ai-limit`; AI выключен по умолчанию.
- Добавлены `history-status` и `prepare-history`: строгие point-in-time срезы с запретом hindsight, включение только статей с `collected_at<=as_of`.
- Генератор **не проставляет** целевые значения 0/1. Проверка меток требует независимого человеческого подтверждения.
- Исторические/ретроспективные срезы со сдвигом времени запрещены в `validate-model`.
- Расширена отчётность модели: train/test prevalences и calibration ECE; исходная временная схема split + embargo сохранена.
- Интегрирована официальная Kaspersky Cybermap iframe-карта, ссылки на оригинальные статистику, новости и описание типов обнаружений.
- Подключены RSS-исследования Securelist EN/RU. Показатели карты не считываются из недокументированных API.
- Добавлены CSV-таблица для ограниченного ручного ввода наблюдений Kaspersky и API `/api/cybermap`.
- Добавлены страницы `/research` и `/cybermap`; CORS/CSP ограничены, iframe разрешён только с cybermap.kaspersky.com.
