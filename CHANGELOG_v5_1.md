# ThreatWatch Global 5.1 — 30 октября 2026

## Исправления на основании реального Windows-лога и `threatwatch.db`

- **Один файл запуска:** `START_THREATWATCH.bat` проверяет наличие Python и зависимостей, при необходимости устанавливает пакеты из `requirements.txt`, запускает локальный сервер, открывает браузер, запускает первый пассивный сбор и включает расписание 6 часов. Старый `start_windows.bat` теперь перенаправляет на него.
- **Управление в браузере:** `/control` — запустить сбор вручную, включить/выключить расписание, посмотреть статус последнего запуска, ошибки внешних источников и скачивать CSV оценок, публикаций и кандидатов. Параллельные сборы запрещены; ИИ выключен.
- **Разметка статей:** `/audit` — сбалансированная проверочная очередь (публикации с/без найденных организаций), открытие источника, ввод всех действительно упомянутых организаций или `NONE`, подсчёт precision/recall/F1 на проверенных материалах. Непроверенные материалы не становятся отрицательными примерами.
- **Кандидаты:** кнопки «Добавить в мониторинг» и «Отклонить» на `/candidate/ID`. При утверждении требуется вручную сверить первоисточник, страну и отрасль. Известные публикации связываются с организацией, без нового скачивания.
- **GDELT HTTP 429:** в одном цикле после 429 следующие запросы GDELT пропускаются. Ошибка записывается в базу, а источник получает паузу 6 часов на последующих запусках. Нет агрессивных повторных попыток или обхода ограничений API.
- **Securelist RU EOF:** русский RSS временно выключен в `sources.json` по умолчанию ввиду нестабильного TLS; английский поток оставлен. Проверка сертификатов не отключена.
- **Имена организаций:** удаляются распространённые журналистские хвосты (`says it was` и т. п.) из *новых* заголовков; старые результаты не переименовываются без ручной проверки.
- **Сетевая безопасность локальной панели:** только loopback, контроль `Host`/`Origin`, CSRF-токены для POST, фиксированный список действий, ограниченный размер формы, экранирование отображаемого контента. Не предоставляет выполнение произвольных команд или доступ через Интернет.

## Ограничения

- Реальная вероятность будущего взлома не вычисляется без независимо размеченной длинной истории с 14-дневными исходами. Индекс 0–40 не является вероятностью.
- Работа внешних серверов из пользовательской сети зависит от их доступности и лимитов. Автотесты проводят сетевое моделирование, но не гарантируют, что любой API всегда отвечает.
- Расписание работает **пока открыто окно приложения**; оно не является службой Windows.
- Программа никогда не скачивает украденные материалы и не обращается к сайтам потенциальных жертв с целью технической проверки.
- **Файл базы пользователя не включён** в релизный архив. Для сохранения накопленной истории перенесите вашу копию `data/threatwatch.db`.
