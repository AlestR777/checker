# ThreatWatch Global 6.0.1

- Почти чёрный фон, фиолетовые акценты и свечение, тонкие границы, нейтральные полупрозрачные панели. Единая тема обзора, форм, карточек и графа.
- Видимая версия каждой страницы, раздел «О приложении» с путём кода и базы, `--version`, локальный API `/api/runtime`.
- Windows desktop открывает новый обзор. Если старое приложение занимает порт, новая копия выбирает свободный из следующих девяти, не подключается к старой и не завершает её.
- Обзор обновляется каждые 8 секунд во время сбора и показывает его состояние; после завершения обновление прекращается.
- Исправлено несоответствие шкал: видимый экспорт из «Управления», терминальная сводка и новый CLI `export risks` используют 0–100.
- Исправлен реальный ложный сигнал: структурированное ransomware-заявление о Lydenburg Toyota не сопоставляется с Toyota Motor Corporation по подстроке Toyota. Требуется точное каноническое название или объявленный алиас.
- В GitHub поставляются исходники, скриншот и отдельный ZIP с уникальным именем.

Контрольный реальный сбор: 505 публикаций, 6 из 8 источников успешно, 4 публикации сопоставлены с текущим каталогом, 389 сохранены для разбора, 300 организаций ожидают проверки. Связи этим сбором не установлены. Это не доказательство их отсутствия; предложения требуют данных и проверки. The Hacker News требует разрешённого перехода на feeds.feedburner.com, CISA возвращает HTTP 403. Сеть и публикация среды в рамках этого исправления не менялись.
