# Источники и способы интеграции (v4)

| Сервис | Использование | Ограничения |
|---|---|---|
| Ransomfeed | Документированные JSON API `/country/France`, `/offset/300` | Объявления группировок, НЕ подтверждённые атаки; 5 запросов в минуту по официальной документации |
| RansomLook | Публичный API заявлений | Может быть недоступен или возвращать тайм-ауты; данные дублируют другие агрегаторы |
| Ransomwhere | Публичный `/api/victims` с названием, страной, отраслью и датой | Перепубликует данные других трекеров, не независимый источник подтверждения |
| GDELT DOC 2.0 | Публичный API поиска новостных публикаций | `sourcecountry` означает страну **издателя**, не страну организации; `seendate` — дата индексирования |
| Google News RSS | Международные тематические запросы | Шум, публикации об одном инциденте из десятков изданий |
| The Record, ZATAZ, 01net, Securelist | Прямые новости и исследования | Не превращают заявления преступников в подтверждённые инциденты автоматически |
| Wikidata | **Только при явном QID**: сведения о parent/subsidiary/ownership | Точность сущности необходимо проверить; записанные там отношения могут устареть |
| Kaspersky Cybermap | Официальный виджет; новости Securelist, как в v3.2 | Глобальная телеметрия детектирований **не** означает реальный взлом конкретной организации |

**Не используются** закрытые учётные записи, криминальные маркетплейсы, утекшие документы, украденные учётные данные, проверка паролей, сетевые сканеры или попытки доступа к организациям.
